# Notebooks

`SANC_Preprocessing_Integration_original.ipynb` is the original working notebook with outputs stripped (the version with outputs is ~16 MB). It is kept for provenance only; the maintained code is in `sanc/` and `pipelines/`. Every pipeline README lists the notebook cell numbers each script was taken from.

All figures and printed results from the executed notebook were extracted to `results/` (`figures/`, `*/logs_*.txt`, and parsed CSV tables).
